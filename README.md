# Дурак: 1 на 1 с ботом

Игра «Дурак» (подкидной) на Python и pygame.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Нужен Python 3.8+ и pygame 2.5+. В VS Code: `File → Open Folder…`, выберите Python-интерпретатор, нажмите F5.

## Главное меню

* **Продолжить** — вернуться к незаконченной партии. Партия сохраняется автоматически после каждого хода,
  поэтому её можно продолжить даже после закрытия игры. Файл сохранения: `~/.durak_save.json`.
* **Новая игра** — открывает выбор сложности бота (*Лёгкий*, *Обычный*, *Сложный*), после выбора сразу начинается партия.
  У сохранённой партии сложность своя, при «Продолжить» она не меняется.
* **Выход** — закрыть игру (партия сохранится).

## Управление в игре

* Клик по карте в вашей руке ходит или бьёт этой картой. Подходящие карты приподняты.
* **Беру** — взять карты со стола.
* **Бито** (или **Хватит**, если бот берёт карты) — завершить раунд. Клавиша `Enter` или `Пробел`.
  Когда вы отбились, карты полсекунды лежат на столе и уходят в бито сами, нажимать не нужно (можно нажать, чтобы ускорить).
* **В меню** — вернуться в меню, партия сохранится. Клавиша `Esc`.
* В меню клавиша `Esc` закрывает игру.

## Правила

* Колода 36 карт (6…туз), у каждого по 6 карт. Нижняя карта колоды задаёт козырь.
* Первым ходит владелец младшего козыря, если козырей нет, то по жребию.
* Бить можно старшей картой той же масти или любым козырем. Козырь бьётся только старшим козырем.
* Подкидывать можно карты тех же достоинств, что уже лежат на столе. За раунд не больше 6 карт
  и не больше карт у защитника.
* Если защитник отбился и атакующий больше не подкидывает, раунд «бито», роли меняются.
  Когда отбивались вы, карты уходят в бито сами после короткой паузы.
  Если защитник берёт, атакующий может подкинуть ещё.
* После раунда добирают до 6 карт: сначала атакующий, потом защитник.
* Когда колода кончилась, тот, кто первым остался без карт, выигрывает. Если карты кончились у обоих, ничья.

## Бот

| Уровень | Что делает |
|---|---|
| Лёгкий | ходит и бьёт почти наугад, подкидывает мало, иногда берёт карты без причины |
| Обычный | ходит младшими некозырными картами, бьёт самой дешёвой картой, подкидывает до 4 карт за раунд, старшие козыри тратит только в крайнем случае |
| Сложный | как обычный, но ходит парами (чтобы было чем подкинуть), подкидывает до 6 карт, берёт только если козырь у него последний |

Логика бота в `durak/bot.py`. Подбор картинок и их соответствие картам — в `durak/sprites.py`.

## Структура

```
main.py              точка входа
durak/
  cards.py           карта, колода
  engine.py          правила и состояние партии (без интерфейса), сохранение в словарь
  bot.py             бот: три уровня сложности
  gui.py             меню и стол на pygame
  sprites.py         картинки карт
  save.py            сохранение и продолжение партии
  assets/cards/      картинки: 00–35 — лицевые стороны, back.png — рубашка
tests/               unittest: правила, бот, сохранение
```

Номера картинок: `масть * 9 + (достоинство − 6)`, масти по порядку ♣ ♥ ♦ ♠.
